# Changes

## 0.1.0 (2026-10-08) — ALPHA

First release (Phase 1).

- New MAVR activity: 3D rooms explored in the browser, with stations, models, images, texts and
  question-bank questions.
- Built-in viewer (`mavrruntime_builtin`) for desktop and phone browsers, with an accessible list
  view that works with a keyboard and a screen reader.
- Gallery walk template (`mavrtemplate_gallery`) with two bundled environments or an uploaded GLB
  room.
- Actions recorded as xAPI statements; grades and completion calculated on the server.
- Teacher reports, privacy provider, backup and restore, course reset and uninstall clean-up.
